How SQLi Works

SQL Injection occurs when user input is improperly sanitized and concatenated directly into a database query. Attackers can manipulate the input to alter the query's logic.

Try These Payloads:
  • ' OR 1=1 -- (Bypasses authentication by making the WHERE clause true)
  • admin' -- (Logs in as admin by commenting out the rest of the query)
