What is IDOR?

Insecure Direct Object Reference occurs when an application provides direct access to objects based on user-supplied input without proper authorization checks. In this lab, changing the user_id parameter in the URL allows you to view profiles of other users, including an Admin.

How to prevent this:
  • Implement robust access control checks to ensure the currently logged-in user is authorized to access the requested resource.
  • Use unguessable indirect references (like UUIDs) instead of sequential integers for identifiers, though this is secondary to proper access control.
