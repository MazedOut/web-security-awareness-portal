What is XSS?

Cross-Site Scripting (XSS) allows attackers to inject malicious client-side scripts into web pages viewed by other users. This happens when the application includes untrusted data in a web page without proper validation or escaping.

Try These Payloads:
  • <script>alert('XSS')</script>
  • <img src=x onerror=alert('XSS')>
  • <h1 style="color:red">HTML Injection</h1>
